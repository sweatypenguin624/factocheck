# 🕵️‍♂️ FactoCheck

**FactoCheck** is a web-based fact-checking platform designed to help users verify the authenticity of information. Built with a modern tech stack, it provides a seamless interface for users to submit claims and receive verification results.

---

## 🚀 Features

- 🔍 **Claim Submission**: Users can submit statements or claims they wish to verify.
- 🧠 **Automated Fact-Checking**: Integrates with external APIs to assess the veracity of submitted claims.
- 📊 **Result Dashboard**: Displays verification results with confidence scores and sources.
- 🛠️ **Admin Panel**: Manage user submissions, monitor system performance, and update verification algorithms.

---

## 🛠️ Tech Stack

| Layer        | Technology            |
|--------------|-----------------------|
| Frontend     | React.js, TypeScript  |
| Backend      | Node.js, Express.js   |
| Database     | MongoDB               |
| Authentication | JWT (JSON Web Tokens) |
| Styling      | CSS Modules           |
| Deployment   | Docker, Heroku        |

## 📦 Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/sweatypenguin624/factocheck.git
   cd factocheck
   ```

2. **Set up the backend**
   ```bash
   cd backend
   npm install
   npm start
   ```

3. **Set up the frontend**
   ```bash
   cd ../frontend
   npm install
   npm start
   ```

4. **Environment Variables**

   Create a `.env` file in both `backend` and `frontend` directories and add the necessary environment variables as specified in the `.env.example` files.

---

## 🧪 Usage

- Navigate to `http://localhost:3000` in your browser.
- Submit a claim you wish to verify.
- View the verification result along with confidence scores and sources.
